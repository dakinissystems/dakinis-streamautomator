# Eliminación de cuenta (StreamAutomator)

Última actualización: 2026-08-04

Puedes solicitar la eliminación de tu cuenta de dos formas:

1. Desde la aplicación  
En Ajustes de usuario, usa la opción para eliminar / borrar la cuenta.

2. Por email de privacidad  
Escribe a privacy@streamautomator.com (o privacy@dakinissystems.com). No designamos DPO; ese correo es el canal de solicitudes de privacidad.

Qué datos se eliminan o anonimizan  
Tras la eliminación, se anonimizan o eliminan los datos personales vinculados a tu cuenta, incluyendo de forma orientativa:

- nombre de usuario
- correo electrónico
- información de perfil
- credenciales de autenticación y sesiones
- integraciones OAuth enlazadas (Google, Twitch, Discord, YouTube, X, Kick), cuando aplique
- clave API de bot/overlay

Qué puede conservarse temporalmente  
Por obligaciones legales, seguridad y moderación, algunos registros pueden conservarse de forma acotada, por ejemplo:

- registros de moderación e informes
- trazas necesarias para prevención de abuso o fraude
- información requerida para cumplimiento normativo

Plazos  
- Las solicitudes desde la aplicación se procesan en el flujo de la app.
- Las solicitudes por email se gestionan según los plazos del RGPD (habitualmente un mes).

## 2. Datos que tratamos

- Cuenta: usuario, email, perfil.
- OAuth: tokens e identificadores de Google, Twitch, Discord, YouTube, X (Twitter) y **Kick** cuando conectas esas plataformas.
- Contenido: publicaciones programadas, eventos, archivos que subes, configuración de encuestas/overlays ligada a tu cuenta.
- Técnicos: logs, IP, diagnóstico de seguridad.
- Clave API de bot/overlay: autentica webhooks tipo Nightbot y overlays OBS.

## 3. Google (login y YouTube)

Si usas **inicio de sesión con Google** o **YouTube**, cumplimos la [Política de datos de usuario de Google API Services](https://developers.google.com/terms/api-services-user-data-policy).

**Scopes mínimos:**

- Login: `profile`, `email`
- YouTube: `youtube.upload`, `youtube.readonly` (solo para funciones de publicación/gestión acordadas)

No vendemos datos de Google ni los usamos para publicidad comportamental. Puedes desconectar integraciones en Ajustes y revocar permisos en https://myaccount.google.com/permissions

## 4. Otras plataformas (Twitch, Discord, X, Kick)

Twitch, Discord, X y Kick se tratan solo para las funciones que actives (p. ej. estado en directo, webhooks, publicación, bots de chat). Debes cumplir también sus términos. Kick usa OAuth 2.1 con PKCE; al conectar Kick pueden recibirse webhooks de eventos de livestream.

## 5. Encargados

Hosting, base de datos (p. ej. Railway / PostgreSQL / Supabase si está configurado), correo (Resend / enrutado Cloudflare cuando aplique) y pagos (p. ej. Stripe) como encargados conforme al RGPD. No vendemos datos personales.

## 6. Conservación y seguridad

Datos mientras la cuenta esté activa o sea necesario por ley. Medidas técnicas razonables (HTTPS, control de acceso, cifrado de tokens de integración cuando aplique).
